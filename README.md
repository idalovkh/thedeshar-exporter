# Экспортер материалов

Расширение для Chrome 119 и новее на Windows и macOS. Оно собирает книгу
с учебной платформы и сохраняет ZIP с материалами для последующего импорта.
Для обеих операционных систем используется один установочный ZIP.

Поддерживаются совместимые сайты школ с собственными доменами (white label).
Откройте содержание книги и нажмите значок exporter. Для нового сайта Chrome
запросит доступ только к этому домену; экспортёр проверит структуру приложения
и подключит его. Несовместимый сайт завершит подключение понятным сообщением.
Каждая книга закреплена за своим сайтом: одинаковые ID на разных доменах
не объединяются. Доступ к медиафайлам на CDN запрашивается отдельно при скачивании.

Сетевые ответы с заданиями принимаются с любых доменов: сервер API или WebSocket
может отличаться от сайта книги. Список разрешённых доменов ответов не используется.
Сбор работает только на подключённой странице материалов; проверка содержимого
и исключение служебных запросов сохраняются.

Глубокая очистка строк и вложенного JSON выполняется при нажатии «Скачать архив»:
каждая запись очищается один раз перед записью во временный файл ZIP. Во время
сбора сохраняются исходные тела заданий без повторной очистки; они могут содержать
личные данные и токены внутри содержимого. Из готового архива эти данные удаляются.
Проверки типов заданий, принадлежности книге, размера и полноты ответа выполняются
при сборе. Адреса страниц и сетевых ответов по-прежнему сохраняются без секретных
параметров; ранее собранные записи доступны без повторного сбора.

Для импорта архивов с новых white-label доменов требуется обновлённый импортёр,
который связывает исходные задания с доменом выбранной книги. Обновите API
до выдачи пользователям расширения с поддержкой новых доменов.

Вставки VK Video сохраняются в исходных данных упражнения и после импорта
воспроизводятся онлайн во встроенном плеере. Обновлённый импортёр восстанавливает
плеер и из старого ZIP, если в нём сохранилось исходное поле `Videos[].Link`.
Чтобы убрать ложные записи о файлах из манифеста, скачайте архив заново из
уже собранной книги в обновлённом расширении. При выпуске сначала обновите API
и воркер импорта, затем расширение.

Экспортёр сохраняет обложки разделов книги из `GetBookCourses.ImageUrl`,
включая разделы без уроков. Эти изображения скачиваются и проверяются вместе
с остальными медиа. Для их переноса нужен импортёр с поддержкой обложек
разделов. В прежних архивах обложка непустого раздела также может быть сохранена
в метаданных его уроков; обновлённый импортёр использует такие данные без
повторного сбора книги, если изображение присутствует в ZIP.

Загрузка каждого содержания книги, урока или раздела ограничена общим сроком
180 секунд. Ожидания, команды восстановления и новая вкладка используют один
дедлайн. Если страница временно отклонила команду до подтверждения перехода,
экспортёр ждёт её готовности и повторяет ту же команду с проверкой документа
и текущего раздела в пределах исходного дедлайна. Это ожидание не требует
обновления расширения и не удаляет сохранённые разделы.
Через 30 секунд без значимого прогресса экспортёр проверяет возможность
повторного запроса заданий. Подтверждённому повтору даётся 15 секунд; при
неподтверждённом протоколе сразу выполняется перезагрузка страницы. В этой сборке
протокол повторного запроса ещё не подтверждён, поэтому такие запросы не отправляются.

После перезагрузки 60 секунд без прогресса запускают восстановление в новой вкладке;
ещё 60 секунд без прогресса или общий предел останавливают сбор. Допускается одна
перезагрузка и одна новая вкладка. Прогрессом считаются ожидаемый маршрут, первое
появление содержимого, подтверждённые задания и увеличение загруженного списка уроков.
Висящие запросы, посторонний трафик,
повторяющиеся индикаторы загрузки и ответы прежнего документа ожидание не продлевают.
Готовая страница сохраняется сразу. Для подтверждённых сетевых ошибок Chrome
сохраняются ограниченные повторы с паузами 2 и 5 секунд в общем бюджете попыток.
Сетевые ошибки распознаются через `webNavigation` для основной вкладки активного сбора.
Ошибки iframe и запросов медиа не считаются сменой книги. Закрытие вкладки,
ручной переход, ограничения доступа или неоднозначная цель прекращают повторы.
Незавершённый сбор остаётся недоступным для скачивания.

Если проверка содержания блокирует автоматический обход, экспортёр показывает
конкретную причину вместо приглашения начать сбор. Отчёт о проблеме доступен
даже до первой попытки сбора и содержит код сработавшей проверки.
Для ошибки кнопки урока отчёт также содержит номер первой проблемной карточки,
число видимых кнопок каждого типа и причину отказа. Кнопку с изменённой подписью
или иконкой экспортёр использует, если она единственная и ID урока подтверждён.

ProgressMe может уточнить адрес первого раздела урока во время чтения ответа.
Экспортёр сохраняет поздние задания, если ответ подтверждает ID открытого
раздела, а урок, книга и документ совпадают. Для поздних метаданных урока
проверяются ID книги и урока. Служебные ответы, завершившиеся во время
перехода, не считаются потерянными учебными данными.

При замене вкладки сохраняются книга, хранилище, контрольные точки и дедлайн.
Начальный `about:blank` в созданной вкладке считается ожиданием, пока браузер
загружает подтверждённый адрес восстановления и совпадает исходный документ.
Посторонний адрес, другой документ или истёкший дедлайн не получают это исключение.
Запись из старой вкладки отключается до подключения новой; запоздалые ответы
не принимаются. Старая вкладка закрывается только после сохранения текущей страницы
и подтверждения заданий в новой. При неудаче закрывается созданная замена,
исходная вкладка и собранные данные остаются. Состояние переноса хранится в сессии
Chrome и переживает перезапуск service worker. В интерфейсе показывается текущий
способ восстановления, в отчёте — время без прогресса и оставшийся бюджет.

Собственная перезагрузка и открытие урока внутри приложения учитываются отдельно
для каждой попытки. Неизменившийся адрес в history-событии старого документа не
подтверждает загрузку нового; запоздалые события прежнего документа не меняют
подтверждённую страницу. Ручная перезагрузка после её открытия останавливает
сбор, даже если адрес остался прежним. После обновления расширения обновите
вкладку книги и заново откройте exporter. Переходы прежней версии не получают
разрешения на восстановление; сохранённые материалы не удаляются. Продолжение
доступно при наличии подтверждённых контрольных точек.

При открытии урока платформа может сначала показать адрес урока без номера
раздела, затем добавить `/section` и только после загрузки перейти к конкретному
первому разделу. Экспортёр дожидается этой последовательности в выбранном уроке
и том же документе. Первый конкретный раздел фиксируется; последующие изменения
раздела без команды экспортёра по-прежнему останавливают сбор.
Перед чтением и действиями экспортёр обрабатывает очередь уведомлений страницы.
Если за время этого ожидания изменились маршрут или состояние сбора, старая
команда не выполняется. Быстрый уход из раздела и возврат на тот же адрес также
требуют нового подтверждения исходных заданий.

Готовый ZIP вместе с заголовками ограничен 4 ГБ (4 000 000 000 байт).
Архив использует ZIP32 без сжатия; ZIP64 не создаётся. Пределы сбора
256 МиБ и отдельного медиафайла 100 МиБ сохраняются.

Книга готовится во временных файлах на диске. ZIP записывается потоком в файл,
выбранный пользователем, и после закрытия проверяется по структуре, размерам
и контрольным суммам. Только после проверки появляется сообщение «Архив сохранён».
Вся книга не собирается в оперативной памяти. Ошибка записи или нехватка ресурсов
завершает попытку понятным сообщением; автоматического ожидания освобождения ресурсов нет.

Перед записью в архив экспортёр определяет формат по содержимому и при наличии
безопасного бюджета памяти сохраняет PNG, JPEG, GIF и AVIF в WebP без потерь.
Он учитывает ориентацию и вписывает изображение в рамку 1920 × 1080 для
горизонтальных и 1080 × 1920 для вертикальных изображений, сохраняя пропорции
без увеличения. Готовый WebP в пределах рамки сохраняется побайтово.
Кодировщик проверяет все полученные после декодирования и масштабирования
пиксели 8-битного sRGB. Для 16-битных и HDR-источников действует то же
преобразование. Экспортёр сохраняет кадры, прозрачность, длительность и повторы
анимаций. Аудио, видео, PDF и SVG записываются в исходном виде.

Обработка идёт локально по одному файлу на профиль Chrome. Число одновременных
скачиваний меняется от одного до шести с учётом доступной памяти, загрузки CPU
и скорости записи. Если безопасного бюджета декодирования нет, экспортёр сохраняет
оригинал только при подтверждённом формате и соблюдении известных ограничений
импортёра. Такой файл сохраняет исходные MIME и расширение, а интерфейс показывает
число изображений без сжатия. Обработка оригинала проверяется при импорте.

Если размеры
изображения нельзя проверить или обработка не удалась, экспортёр показывает
проблемный файл и автоматически сохраняет архив с доступными материалами.
Количество недоступных файлов не ограничивает сохранение; пропуски остаются
в manifest, счётчиках, предупреждениях и отчёте. Материалы сохраняются для повторной попытки. Декодирование ограничено 64 млн пикселей
и 16 384 пикселями на сторону.

Экспортёр записывает одинаковые медиа в ZIP один раз по SHA-256 и размеру
после обработки изображений. У преобразованных изображений в манифесте указываются имя
с расширением .webp, тип image/webp и итоговый размер; у сохранённых оригиналов — исходные метаданные. Исходные ссылки и ID
сохраняются. Лимит архива учитывает общий файл один раз. Если ссылки
разрешаются в один точный адрес скачивания, они используют общий результат
запроса. SHA-256 и контрольная сумма ZIP вычисляются при одном чтении медиа.

## Установка и перенос книги

1. На платформе импорта откройте «Материалы» → «Личные материалы» → «Импортировать»
   и нажмите «Как получить архив». В открывшейся инструкции нажмите
   «Скачать экспортер». Сотрудникам эта инструкция также доступна
   из окна импорта библиотеки админки. Скачивание требует входа и прав на импорт.
2. Распакуйте ZIP в постоянную папку. Не удаляйте и не перемещайте эту папку
   после установки.
3. Откройте `chrome://extensions`, включите «Режим разработчика», нажмите
   «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
4. Откройте содержание книги на учебной платформе. После установки или обновления
   расширения закройте старую страницу exporter и обновите вкладку книги.
   Это подключит расширение к странице. Дождитесь загрузки книги.
5. Нажмите значок exporter во вкладке книги.
   На новом домене разрешите подключение сайта, если Chrome запросит доступ.
6. Нажмите «Собрать книгу». Оставьте вкладки источника и экспортера открытыми
   и не переключайте страницы книги во время сбора.
7. Дождитесь завершения и нажмите «Скачать архив». Если Chrome запросит
   доступ к доменам файлов книги, разрешите его и нажмите «Скачать архив» ещё раз.
   Выберите место сохранения ZIP. Дождитесь сообщения «Архив сохранён».
8. Вернитесь на платформу импорта, нажмите «Вернуться к импорту» и выберите ZIP с книгой
   в поле «Архив с материалами». Если окно закрыто, снова нажмите «Импортировать».
   Установочный ZIP расширения для импорта материалов не подходит.

Для переноса ещё одной книги откройте её содержание на учебной платформе
и снова нажмите значок exporter в Chrome. Для новой книги откроется отдельная
страница exporter. Предыдущий сбор остаётся на своей странице; повторное нажатие
значка на той же книге возвращает к её сбору. Внутри exporter нет выбора или
переключения книг. Сохранённые материалы остаются в профиле Chrome после закрытия
браузера. Чтобы вернуться к ним, откройте ту же книгу и нажмите значок exporter.

Разные книги можно собирать одновременно в отдельных вкладках учебной платформы.
Скачивание файлов и подготовка изображений выполняются по очереди на профиль
Chrome; ожидающая книга показывает причину ожидания. Если сохранены подтверждённые
разделы, после остановки доступна кнопка «Продолжить сбор».

Перед сохранением раздела экспортер ждёт сохранения исходного ответа сайта
для текущего открытия и завершения отображения заданий. Смена адреса и оставшиеся
на странице упражнения предыдущего раздела не подтверждают готовность.
Пустые разделы, включая домашнюю работу, подтверждаются исходным ответом сайта
с пустым списком заданий. Записи предыдущих открытий и сборов не заменяют новый ответ.
На получение данных и отображение раздела отводится одно общее ожидание на попытку.
Если исходные задания отсутствуют, список неполон, загрузка зависла или содержимое
не появилось, экспортер повторно загружает тот же раздел не более двух раз.
После неудачных попыток сбор останавливается, ZIP недоступен; ранее собранные
материалы сохраняются. Неподтверждённая страница не записывается как снимок.

Копия задания для преподавателя находится на исходной позиции в уроке
и скрыта от учеников. В редакторе откройте приватную заметку
этого блока, чтобы посмотреть исходную разметку и вручную исправить задание.

Инструкция содержит иллюстрации установки и переноса. Она временно заменяет
окно импорта: кнопка возврата, крестик и Escape возвращают к импорту, сохраняя
выбранный файл. Шаги обновления доступны в пункте «Как обновить экспортер».

Интерфейс использует тёмно-синюю палитру без брендинга, отдельную карточку
книги и индикатор шагов. Шрифт Nunito Sans включён в расширение и не требует
запросов к внешним сервисам. Компоновка адаптируется к узкому окну; системная
настройка уменьшения движения отключает анимации.

Кнопка «Как пользоваться» в шапке открывает встроенную инструкцию: четыре
шага переноса, подсказки при остановке сбора и порядок обновления расширения.
Инструкция доступна без интернета и во время сбора. Крестик, «Понятно» и Escape
закрывают её и возвращают фокус на кнопку; выбранная книга и ход сбора сохраняются.

На каждом этапе интерфейс выделяет одно основное действие: собрать материалы,
скачать архив, после скачивания — скачать его ещё раз. Для следующей книги
показана подсказка о повторном запуске через значок расширения. Во время работы
доступна остановка. Отчёт об ошибке показывается отдельной кнопкой. Меню служебных
действий, очистки, перехода к книге и переподключения в интерфейсе нет.

Подключение, сбор и подготовка архива показывают круговой индикатор в том же
стиле, что и загрузка в импортере. Когда объём работы известен, внутри круга
появляется процент; иначе индикатор вращается без него. Рядом видны количество
уроков, файлов и объём данных. Уже подтверждённое название сохраняется при
повторной проверке связи. Отмена, ошибки и результат доступны в той же области.
Важные инструкции о сохранности данных остаются видимыми; скринридер дополнительно
сообщает текущую операцию.

Если переход к уроку не произошёл и в исходной вкладке осталось то же
оглавление, экспортер повторит открытие один раз. При обрыве сетевого запроса
за файлом предусмотрено до трёх попыток на файл.

Если файлы скачать или обработать не удалось, экспортёр завершает обработку
всего списка и автоматически сохраняет доступные материалы без окна согласия.
Все файлы должны иметь конечный результат: отсутствие результата, дубликаты
логических записей и некорректные байты по-прежнему запрещают создание ZIP.
Отказ в доступе к CDN считается пропуском. После отказа в запросе разрешения
следующее нажатие «Скачать архив» открывает выбор ZIP без повторного запроса.
Разрешения можно выдать в настройках Chrome; следующая попытка проверяет их заново.

Новая попытка через «Скачать архив» проверяет доступность и актуальность файлов
без обхода книги. Проверенные подготовленные файлы сохраняются в дисковом кеше:
при неизменившемся сильном ETag повторное скачивание тела не нужно. Без такого
валидатора файл скачивается полностью, но совпавший исходный SHA-256 позволяет
пропустить обработку изображения. Ошибка HTTP не разрешает подставить старый файл.

В manifest остаются исходные ссылки, статусы, причины недоступности файлов,
количество пропусков и предупреждения. После сохранения интерфейс показывает
«Архив с проблемами» и кнопку «Скачать отчёт о проблеме». JSON можно самостоятельно
передать в поддержку; автоматически он не отправляется.

Импортёр пропускает отдельные непереносимые упражнения и публикует оставшиеся
без ограничений количества или доли потерь. В прежних DOM-архивах сохраняется
доступный очищенный текст; неизвестное число исходных заданий не запрещает перенос.
Повторные ссылки на один недоступный URL учитываются один раз. Полностью потерянная
книга, незавершённый сбор страниц или раздел без авторских данных запрещают импорт;
подтверждённо пустые исходные разделы допустимы. Проверка полезного содержимого
повторяется при загрузке подготовленного плана. Проверки владельца, счётчиков,
ссылок, ресурсов и целостности архива сохраняются.

Адрес редактора и адрес файла могут различаться. Для ссылок вида
`files/<семейство>/<UUID>` экспортер ищет полный адрес того же файла среди
сохранённых ссылок книги. Путь и параметры должны совпадать; порядок файлов
не влияет на результат. Запрос разрешения Chrome относится к найденному
медиадомену, например домену ProgressMe или Edvibe.

Если найдены разные полные адреса одного файла, скачивание этого файла
останавливается с причиной `ambiguous_media_url` в отчёте о проблеме. При
отсутствии полной ссылки только подтверждённое семейство `LessonExerciseImages`
использует `media-y.progressme.ru`. Для остальных ссылок действует прежнее
разрешение адреса. Экспортер не перебирает возможные медиадомены.

Исходные ссылки в книге и manifest сохраняются для привязки файлов при импорте;
в отчёте указан фактический адрес запроса. Исправление работает с уже доступными
сохранёнными записями. После обновления расширения заново откройте его страницу
из вкладки книги; порядок обновления приведён ниже.

После перезагрузки экспортер дожидается ответа нового документа, затем
проверяет загрузку заданий. Перед следующим переходом он заново читает список
разделов. Если вкладка перезагрузилась между проверкой и сохранением или кликом,
сбор останавливается, сохраняя уже полученные снимки. При обновлении расширения
перезагрузите вкладку учебника, чтобы её скрипт поддерживал проверку документа.

Если сбор остановился, проверьте сообщение об ошибке. Кнопка «Скачать отчёт о проблеме»
появляется только после остановки из-за ошибки, включая сбой до сохранения первой
страницы. Во время работы, после успешного завершения и ручной отмены она скрыта;
новая попытка скрывает отчёт о предыдущей ошибке. В окне ошибок файлов отчёт
доступен, пока скачивание ждёт решения пользователя. Кнопка сохраняет отдельный JSON
со сведениями о подключении, сборе страниц, попытках загрузки файлов и подготовке
ZIP. Для файлов с ошибками отчёт содержит HTTP-статус, фактический Content-Type,
размеры, длительность, номер попытки и первую страницу, где встретилась ссылка.
В событиях ожидания готовности страницы и итоговой ошибке сбора сохраняется
`readinessReason` — причина неготовности. Для содержания книги поле `bookState`
содержит `visibleLessons` — количество распознанных видимых карточек уроков,
и `expectedLessons` — ожидаемое количество из данных платформы. Пока ожидаемое
количество неизвестно, `expectedLessons` отсутствует; известный ноль сохраняется.
При неподдерживаемом типе ответа экспортер исследует не более первых 1024 байт
в течение одной секунды и записывает только распознанный формат, например HTML
или PNG. Это помогает отличить страницу ошибки от файла с неверным Content-Type.

Некоторые изображения сервер файлов отправляет с типом `text/plain`.
Экспортер принимает такой ответ как PNG только после чтения всего потока и
проверки сигнатуры, структуры, границ и CRC чанков, обязательных IHDR/IDAT/IEND
до корректного IEND. Хвост после этого блока разрешён: перед удалением весь
PNG-префикс проверяется потоковым валидатором, включая CRC всех блоков.
Пиксели при этой проверке не распаковываются.
Правило поддерживает подтверждённые PNG по адресам Docstorio `/files/Rules/`
и не зависит от домена уже разрешённого файла. Удалять его следует, если
поддержка обнаруженных источников с неверным MIME больше не требуется.

Перед обработкой принятый файл получает тип `image/png`. В отчёте остаётся
серверный `mimeType: text/plain` и добавляется `effectiveMimeType: image/png`.
Повреждённый или усечённый PNG отклоняется с причиной `invalid_png`. HTML,
JSON, текстовые ссылки и другие неподдерживаемые MIME по-прежнему не принимаются
как медиа. После преобразования в ZIP записывается WebP, а исходный адрес и
привязки к заданиям сохраняются. Режим без кодирования сохраняет подтверждённый
PNG без хвоста. Размер HTTP-ответа, лимиты и прогресс учитывают все полученные
байты. Исходные SHA-256, размер и ETag идентифицируют источник в кеше; размер
и хеш результата вычисляются после обработки. Нормализация записывается
в диагностику как `png_trailing_bytes_removed` с числом удалённых байтов.
Ошибки метаданных сохраняются с причиной `image_dimensions_invalid`.

Кнопка отчёта остаётся доступной после сохранения архива с пропусками.
Отчёт хранится в текущей сессии Chrome, переживает перезагрузку вкладки и
перезапуск фонового обработчика расширения. Новый принятый сбор
заменяет прежний отчёт. Повторное скачивание заменяет сведения
о предыдущей попытке скачивания, сохраняя ход сбора. Полный перезапуск Chrome,
обновление или перезагрузка расширения очищают отчёт. Старые сборы показывают
доступный прежний журнал с отметкой о неполной диагностике.

Отчёт ограничен одним MiB: при переполнении сначала сокращаются успешные и
повторяющиеся события, затем старейшие ошибки; количество пропущенных записей
указывается в JSON. Если сохранение отчёта не удалось, текущую копию всё ещё
можно скачать из открытой вкладки; в JSON появится отметка об ошибке хранения.
Адреса записываются без параметров и фрагментов. Содержимое заданий, сырые ответы,
cookies и данные входа в отчёт не попадают. Он не включается в архив книги и
автоматически никуда не отправляется: передайте скачанный JSON в поддержку
самостоятельно.

Код `document_load_timeout` означает, что ответ нового документа не появился
за время ожидания. Код `navigation_stale` указывает, что прочитанный список
или его кнопки успели измениться до перехода. В отчёте о проблеме дополнительно
сохраняется контекст навигации: событие Chrome, фаза и причина решения, browser
document ID и последние 32 события перехода. Фактически наблюдавшийся адрес
записывается только при наличии подтверждения браузера; последний известный
адрес остаётся отдельным контекстом. Идентификатор контент-скрипта и подтверждение
открытия заданий остаются внутренними.
Код `section_render_timeout` означает, что адрес раздела открыт, но сайт
не показал ни задания, ни пустое состояние. `section_loading_timeout` указывает
на оставшийся индикатор загрузки, `author_data_missing` — на отсутствие исходных
заданий текущего открытия, `author_data_incomplete` — на неполный исходный список.
Подтверждение открытия используется только внутри расширения и не входит
в архив материалов или скачиваемый отчёт.

Код `exporter_binding_mismatch` означает, что не удалось подтвердить связь
окна экспортёра с выбранной книгой. Поле `binding` содержит безопасную причину
`cause` и имя отклонённой команды `operation`: отсутствие или неоднозначность
контекста окна, ошибку его чтения, замену документа, другой адрес окна,
несовпадение книги или исходной вкладки. Эти сведения остаются и в локальной
копии отчёта, если его сохранение в текущей сессии не удалось. Адрес окна
расширения и идентификатор его документа в отчёт не включаются.

## Независимые сборы и восстановление

Сбор с подтверждёнными разделами можно продолжить после остановки или полного
перезапуска Chrome. Откройте ту же книгу — содержание, урок, раздел или домашнюю
работу — и нажмите значок exporter, затем «Продолжить сбор». Если исходная вкладка
осталась внутри урока, расширение само вернёт её к сохранённому содержанию после
нажатия кнопки. Расширение заново подтверждает доступ и сравнивает
списки уроков и разделов. Незавершённый раздел открывается повторно. Изменение
структуры останавливает продолжение без удаления прежних материалов; для
получения текущей книги откройте содержание и выберите «Собрать заново».

Продолжение сохраняет ранее полученные задания, ответы и даты снимков. Равенство
оглавления не доказывает, что задания не редактировали. Для обновления всех
заданий используйте «Собрать заново». Подтверждение раздела записывается только
после сохранения его снимка и полного исходного ответа. Прежние материалы без
таких контрольных точек сохраняются, но не считаются подтверждёнными для пропуска.

При однозначных исходных ID переход к следующему уроку выполняется без возврата
к содержанию; оглавление проверяется в начале и конце. Если ID неоднозначен,
используется обычное открытие через содержание. Если подтверждённый прямой адрес
не загрузился, действуют прежние ограниченные повторы и остановка с причиной:
ошибка загрузки не считается разрешением на другой переход. Защита от ручной
смены страницы и запоздалых ответов сохраняется.

Кэш готовых медиа находится в отдельном OPFS-каталоге и ограничен 8 ГБ уникальных
файлов и 20 000 привязок адресов. Это дисковое место, а не размер оперативной
памяти. Давно неиспользуемые записи вытесняются; ошибка дополнительного
кэширования не прерывает текущий экспорт. Проверка и копирование идут порциями
до 1 МиБ. Число загрузок по-прежнему ограничено шестью, обработчик изображений
остаётся один. Секретные параметры ссылок не записываются в индекс открытым текстом.

Прямое получение заданий внутренними запросами источника не включено:
сохранённые данные содержат ответы, но не проверенный протокол запросов.
Синтетические фикстуры не подтверждают работу на реальном сайте. До отдельной
проверки структуры запросов и полной эквивалентности заданий, ответов, настроек
и медиа используется обычный обход. Параметры авторизации и сетевые дампы
для этой проверки не следует сохранять или передавать в отчётах.

Книга определяется доменом источника и ID книги. Повторное нажатие значка
экспортера из той же исходной вкладки возвращает к её существующему окну; другой учебник получает отдельный
сбор. Одна исходная вкладка обслуживает один активный сбор. Переключение этой
вкладки на другую книгу останавливает текущий обход с сохранением материалов.
Остановленный сбор нужно продолжить до завершения перед скачиванием ZIP.

Связь окна с книгой проверяется через собственные контексты расширения
(`chrome.runtime.getContexts`). Это работает и в Chrome, который скрывает
адрес вкладки расширения в `chrome.tabs.get`; разрешение `tabs` не требуется.
Проверка сопоставляет книгу, исходную вкладку и документ отправителя.
При открытии старого адреса экспортёр сначала переходит на адрес с актуальной
привязкой, затем читает состояние книги. Пока проверяется начало сбора,
кнопка остановки отменяет ожидающую попытку; запоздалый ответ не возобновляет её.

При закрытии исходной вкладки экспортер сообщает о потере связи и предлагает
повторно открыть книгу, нажать значок exporter и закрыть старую страницу экспортера.
Повторно открытая книга получает страницу с привязкой к новой исходной вкладке;
сохранённые материалы остаются доступными. Завершённый архив можно скачать и
со старой страницы перед её закрытием. При отсутствии ответа от открытой вкладки
экспортер просит обновить книгу и запустить расширение заново, не утверждая,
что пользователь закрыл вкладку.

Ответ скрипта учебника ожидается не более десяти секунд. Общий срок ожидания
раздела включает время запросов. Остановка прерывает ожидание и освобождает
вкладку без очистки материалов; запоздалые ответы прежнего запуска не изменяют
новый сбор. Код `source_timeout` в отчёте означает, что учебник не ответил вовремя.

Постоянный каталог подключает прежние записи IndexedDB v3 текущей сессии по
исходным ключам. Область хранения сохраняется в `chrome.storage.local`, поэтому
после перезапуска браузера доступен тот же набор данных. Материалы не копируются
и не удаляются. Дубликаты остаются отдельными сохранёнными результатами. Переход
нужен только для сохранившихся записей без `workspaceId`; его можно удалить после
прекращения поддержки таких записей. Привязки к вкладкам и разрешения управления
остаются сессионными и после перезапуска подтверждаются заново.

Для проверки перехода в настоящем IndexedDB откройте
`test/workspace-catalogue-browser.html` через локальный HTTP-сервер. Сценарий
проверяет прежние записи, независимость второй книги, очистку и повторное
подключение к хранилищу на отдельной тестовой базе.

## Обновление установленного расширения

1. До обновления остановите сбор. Завершённую книгу рекомендуется дополнительно
   сохранить в ZIP. Для сохранения данных оставьте тот же профиль Chrome и папку
   расширения; удаление расширения удаляет и его локальное хранилище.
2. Скачайте новую сборку на платформе импорта и закройте вкладку экспортера.
3. Полностью замените файлы расширения в прежней папке, сохранив её путь.
4. В `chrome://extensions` нажмите значок перезагрузки на карточке exporter.
5. Обновите вкладку книги, чтобы подключить новую версию расширения.
   Дождитесь загрузки и снова нажмите значок exporter в этой вкладке.

Скачивание новой сборки само по себе не обновляет установленное расширение.
Для перехода с прежнего формата локального хранилища используйте отдельную
[процедуру перехода к 0.3.15](../docs/content-iteration8-runbook.md#экспортёр).
Очистка локального хранилища из этой процедуры не является обычным шагом
всех последующих обновлений.

## Проверка и выпуск

Нужен Node.js 20 или новее. Команды выполняются из этого каталога.

Готовый кодировщик WebAssembly включён в `src/vendor/webp` и не загружается
из сети при установке или скачивании книг. Для его пересборки активируйте
Emscripten 5.0.5 и выполните `bash scripts/webp/build.sh`. Скрипт сверяет SHA-256
исходников, обновляет модуль и лицензии; `npm run check` проверяет хеши готовых файлов.
Для сравнения сборок и проверки импорта используйте
[стенд приёмки на реальной книге](test/acceptance/README.md).

Изолированная проверка white-label подключения, ошибок навигации Chrome,
повторов с паузами 2 и 5 секунд и загрузки дольше 60 секунд:

```sh
node test/acceptance/source-navigation-chrome.mjs /private/tmp/unique-source-navigation-run
```

Стенд создаёт отдельный профиль Chrome и синтетический HTTPS-сайт, записывает
результаты и хеши проверенных модулей в `report.json`, затем удаляет профиль.
Доступ к тестовому домену предварительно выдан только во временном манифесте;
нативное окно выдачи разрешения этим сценарием не проверяется.

Проверка зависшей загрузки, перезагрузки и продолжения в новой вкладке с одним
дедлайном, сохранённым хранилищем и закрытием старой вкладки после записи данных:

```sh
node test/acceptance/stall-recovery-chrome.mjs /private/tmp/unique-stall-recovery-run
```

Сценарий запускает поставляемый код в отдельном профиле Chrome на синтетическом
сайте; время ожидания ускоряется тестовыми часами. Реальную книгу Edvibe и
повтор сетевого запроса заданий этот стенд не проверяет.

Для выпуска PNG-нормализации и переноса без числовых ограничений потерь сначала
отдельно разверните обновлённые API и worker. Прежний импортёр продолжит отклонять
архивы с большими потерями. Подготовка ZIP не выполняет коммит, пуш или развёртывание.

1. Согласованно повысьте `version` в `manifest.json` и `package.json`.
2. Выполните:

   ```sh
   npm run check
   npm test
   npm run package
   ```

3. Возьмите созданный `dist/exporter-X.Y.Z.zip`. Упаковщик включает
   `manifest.json`, `exporter.html` и `src`; не загружайте весь проект или
   весь `dist`, где могут находиться старые версии и архивы книг.
4. Проверьте установку расширения и перенос книги на платформу импорта.
5. В приватном бакете Timeweb `thedeshar-s3` сохраните предыдущую сборку
   под именем с номером версии. Новую сборку загрузите как
   `exporter/latest.zip`, заменив предыдущий объект.
6. Проверьте скачивание в платформе и админке. Для отката замените
   `exporter/latest.zip` проверенным архивом предыдущей версии.

После замены ZIP повторный деплой платформы, админки или API не нужен.

Для проверки встроенной инструкции запустите локальный HTTP-сервер из этого
каталога, например `python3 -m http.server 4179 --bind 127.0.0.1`, и откройте
`http://127.0.0.1:4179/test/help-browser.html`. Проверка использует тестовую книгу
и настоящий браузерный диалог: открытие, фокус, оба способа закрытия кнопкой,
раскрываемые подсказки и сохранность состояния экспортера. Дополнительно
проверьте Escape, обход Tab, узкое окно и открытие инструкции во время сбора
в `test/preview.html?tab=7&scenario=collecting`.

## Доставка через API

Платформа использует `GET /api/v1/materials/exporter/download` в выбранном
кабинете преподавателя; админка —
`GET /api/v1/admin/materials/exporter/download` с правами сотрудника.
На каждое нажатие API проверяет доступ и наличие ZIP, затем возвращает
`{ url, expires_at }` со свежей подписанной ссылкой на пять минут.
Браузер скачивает ZIP непосредственно из S3.

Ссылку из панели Timeweb с параметрами `X-Amz-*` нельзя записывать
в исходники или настройки фронтенда: после истечения срока она перестанет
работать. Сам бакет остаётся приватным.

API использует текущие серверные S3 endpoint, регион и credentials.
`EXPORTER_S3_BUCKET` задаёт бакет экспортера и при отсутствии значения
наследует `S3_BUCKET`. В production укажите `EXPORTER_S3_BUCKET=thedeshar-s3`.
Серверному ключу нужен доступ к чтению и проверке наличия
`exporter/latest.zip` в этом бакете. Ключ объекта фиксирован и не принимается
от браузера. Объект не относится к учебным медиа и их CDN/грантам доступа.

Для первого выпуска настройте доступ API к объекту, выпустите backend,
затем платформу и админку существующими ручными workflow. Проверяйте оба
сценария с разрешёнными ролями, отказ без входа и ошибки отсутствующего ZIP
или недоступного хранилища.

# Сборка WebAssembly кодировщика

Для обычной упаковки расширения используйте готовый кодировщик из
`src/vendor/webp`. В браузере его файлы читаются из пакета расширения.
Пересобирать модуль нужно при изменении `codec.c` или закреплённых версий
зависимостей.

Установите [Emscripten SDK 5.0.5](https://github.com/emscripten-core/emsdk/tree/5.0.5)
и активируйте его в текущей оболочке (`source /path/to/emsdk/emsdk_env.sh`).
Из каталога экспортёра запустите:

```sh
bash scripts/webp/build.sh
node --test test/webp-codec.test.mjs
```

Скрипт скачивает исходники libwebp 1.6.0 и проверяет SHA-256 до распаковки.
Для сборки с готовым архивом исходников укажите
`bash scripts/webp/build.sh src/vendor/webp /path/to/cache`.
Упаковываются бинарник, сгенерированный ES модуль, лицензии зависимостей и
контрольные суммы; исходники и инструменты сборки в ZIP расширения не входят.

У модуля один поток и не более 384 МиБ линейной памяти. Он принимает кадры
RGBA до 1920 × 1080 или 1080 × 1920, проверяет размеры и сравнивает декодированные
пиксели WebP с входными, включая RGB при нулевой альфе. Декодированием и
масштабированием исходных файлов занимается Chrome.
